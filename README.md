
Бұл жоба қауіпсіз тіркелу және жүйеге кіру үшін жасалған.
Мен бұл жобада келесі технологияларды қолдандым: Java, Spring Boot, Spring Security, PostgreSQL дерекқоры және JWT.

Жобаның негізгі функциялары мен жасалған жұмыстар:
1. Тіркелу және кіру жүйесі: Қолданушының паролі BCrypt арқылы хэштелді (қорғалды).
2. JWT аутентификация: Жүйеге кіргенде қауіпсіз токен беріледі және API сол арқылы қорғалады.
3. TLS шифрлау: Деректердің байланысы KeyStore арқылы шифрланып беріледі.
4. File Integrity Monitor: WatchService арқылы файлдардың өзгеруі бақыланады, өзгерсе ескерту жасалады.
5. Сигнатуралық сканер: Қауіпті кодтарды (мысалы EICAR) байт деңгейінде іздеп табады.

Сонымен қатар, жобада 10 тест жазылды және GitHub-та барлық талапқа сай коммиттер жасалды.
